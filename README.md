# 🧮 Modern Calculator

A sleek, responsive, and feature-rich calculator web application built with clean code practices. Designed to handle everyday calculations with a smooth user experience and an intuitive interface.

---

## ✨ Features

- **Standard Arithmetic Operations:** Addition, subtraction, multiplication, and division.
- **Responsive Design:** Adapts smoothly across desktop and mobile screen sizes.
- **Clean User Interface:** Modern styling with clear button grids and distinct displays for input and results.
- **Keyboard Support (Optional):** Allows quick number-crunching directly from your keyboard.

---

## 🛠️ Tech Stack

- **HTML5** – Markup structure and layout
- **CSS3** – Styling, flexbox/grid layouts, and responsive design
- **JavaScript (ES6+)** – Interactive calculation logic and DOM manipulation
